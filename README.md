# ColorViewer

A lightweight browser tool that turns pasted color values into a visual
palette. It is useful for quickly reviewing, comparing, and presenting a set
of colors without installing an application.

## Features

- accepts multiple color values at once;
- renders a responsive grid of swatches;
- keeps the input and preview visible side by side;
- runs entirely in the browser with no backend or build step.

## Run locally

Open `index.html` in a modern browser, or serve the directory:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000>.

The hosted version is available at
<https://xxkotfejxx.github.io/ColorViewer/>.

## Technology

HTML, CSS, and vanilla JavaScript are contained in a single page.
